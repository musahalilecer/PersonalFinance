# Personal Finance & Financial Freedom Tracker

A sophisticated Android application built with **Kotlin** and **Jetpack Compose**, designed to help users manage passive income, track expenses, and analyze their journey toward financial freedom.

## 🚀 Overview

This project is not just a simple expense logger; it is a comprehensive financial companion. It integrates **Clean Architecture** and **MVVM** to provide a scalable, testable, and robust solution for modern personal finance management.

## ✨ Key Features

* **Financial Freedom Analysis:** Advanced algorithms to calculate and visualize your progress toward financial independence.
* **Passive Income Tracking:** Dedicated modules to manage and monitor income streams beyond active work.
* **Budget Optimization:** Smart insights and psychological feedback to help users optimize their spending habits.
* **Dynamic Dashboard:** Real-time financial health overview with intuitive data visualization.
* **Automated Categorization:** Efficient tracking of expense items and income categories.
* **Goal Setting:** Tools to define, track, and reach long-term financial milestones.

## 🛠 Technical Stack

* **Language:** 100% Kotlin
* **UI Framework:** Jetpack Compose (Declarative UI)
* **Architecture:** Clean Architecture + MVVM (Model-View-ViewModel)
* **Dependency Injection:** Hilt (Dagger)
* **Local Storage:** Room Database (SQLite abstraction)
* **Asynchronous Flow:** Kotlin Coroutines & StateFlow/SharedFlow
* **Navigation:** Jetpack Compose Navigation
* **UI Components:** Material Design 3 (M3)

## 🏗 Architectural Design

The app adheres to strict software engineering principles:
* **Clean Architecture:** Separation of concerns between Data, Domain, and Presentation layers.
* **SOLID Principles:** Ensuring the codebase is maintainable and open for future enhancements.
* **Reactive UI:** Leveraging StateFlow to ensure the UI stays in sync with the underlying data source.

## 🏁 Getting Started

### Prerequisites
* Android Studio Ladybug or later
* JDK 17+
* Min SDK: 24 (Android 7.0+)

### Installation
1.  Clone the repository:
    ```bash
    git clone [https://github.com/musahalilecer/PersonalFinance.git](https://github.com/musahalilecer/PersonalFinance.git)
    ```
2.  Open in Android Studio.
3.  Let Gradle sync finish.
4.  Run on an emulator or physical device.
